## `htmlsanitizer/` and `spec/html-sanitizer-vectors.json`

The `htmlsanitizer` package is an independent Go implementation of DOMPurify's string sanitization behavior. Its default tag and attribute allowlists, URI rules and element, attribute and namespace checks are ported from DOMPurify's source. `spec/html-sanitizer-vectors.json` includes DOMPurify's published test payloads, and its expected outputs were generated by running DOMPurify.
